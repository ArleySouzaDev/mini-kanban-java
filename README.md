# Mini Kanban Java

Sistema de gerenciamento de tarefas estilo Kanban, construído aos poucos
para estudar **Programação Orientada a Objetos em Java**.

## 🎯 Objetivo
Aprender POO na prática, um pilar por vez, com commits que
registram a evolução do projeto.

## 🗺️ Progresso
- [x] Aula 1: Abstração, Classes e Objetos
- [x] Aula 2: Atributos, Métodos e Construtores
- [x] Aula 3: Encapsulamento
- [] Aula 4: Enums e Composição
- [ ] Aula 5: Herança
- [ ] Aula 6: Polimorfismo
- [ ] Aula 7: Classes Abstratas
- [ ] Aula 8: Interfaces
- [ ] Aula 9: Coleções e Generics
- [ ] Aula 10: Exceções
- [ ] Aula 11: Boas práticas e SOLID

## ▶️ Como executar
```bash
javac src/*.java
java -cp src Main
```
